Academy Base

Common models, catalogs and business rules for the Academy addons.

Overview

Academy Base provides the shared foundation for the Academy modules in Odoo 18. It defines the main training catalogs, training programs and actions, students, teachers, enrolments and the common synchronization and maintenance mechanisms used by dependent addons.

Features

  • Training frameworks, programs, modules and program lines.
  • Training actions and child training groups.
  • Full and partial student enrolments.
  • Company-specific student sign-ups.
  • Teacher assignments at action and action-line level.
  • Synchronization from programs to actions and from actions to groups.
  • Multi-company security rules and Academy user roles.
  • Scheduled maintenance tasks and QWeb reports.

Installation

PostgreSQL requirement

The PostgreSQL extension btree_gist must be enabled manually in every database where academy_base is installed. 

CREATE EXTENSION IF NOT EXISTS btree_gist;

The module does not install PostgreSQL extensions automatically. The database role used by Odoo may not have, and normally should not require, sufficient privileges to create them.

Once the PostgreSQL requirement and the module dependencies are available, update the Odoo Apps list and install Academy Base.

Usage

The module adds the main Academy menu with access to monitoring, community, catalog, tools and advanced management areas. Available options depend on the user's Academy security groups.

Academy-specific configuration is available from Settings → Academy.

Technical notes

Business integrity is primarily enforced through the Odoo ORM and model constraints. Database constraints are retained where atomic database-level enforcement is appropriate, such as enrolment overlap prevention.

academy_base is a foundational dependency for other Academy addons. Changes to its models, fields, constraints or security rules should therefore be reviewed against dependent modules.
